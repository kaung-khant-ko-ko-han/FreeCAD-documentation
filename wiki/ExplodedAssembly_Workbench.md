# <img alt="ExplodedAssembly Workbench icon" src=images/ExplodedAssembly_workbench_icon.svg  style="width:64px;"> ExplodedAssembly လုပ်ငန်းခွင် (Workbench)

 

## နိဒါန်း

The <img alt="" src=images/ExplodedAssembly_workbench_icon.svg  style="width:24px;"> [ExplodedAssembly Workbench](ExplodedAssembly_Workbench.md) သည် အစိတ်အပိုင်းများ တပ်ဆင်စုစည်းမှု (Assembly) များ၏ ပွတ်ခင်းပြသခြင်း (exploded views) နှင့် အင်မေးရှင်းများ (animations) ဖန်တီးရန် အသုံးပြုသော ပြင်ပ လုပ်ငန်းခွင် (external workbench) တစ်ခုဖြစ်သည်။

 
### အင်္ဂါရပ်များ

-   အစိတ်အပိုင်းများ တပ်ဆင်စုစည်းမှု (Assembly) များ၏ လှပသော ပွတ်ခင်းများကို ဂရပ်ဖစ်အတိုင်း ဖန်တီးနိုင်သည် (ကုဒ် မလိုပါ)  
-   ခွဲထဲပွတ်ခင်း အုပ်စုများ (sub-exploded groups) ဖန်တီးနိုင်သည်  
-   သဘာဝကျသော ဖြုတ်ထုတ်ခြင်းများအတွက် screws များနှင့် nuts များကို လှည့်ပေးနိုင်သည် (rotation)  
-   ပေးထားသော အကူအညီ Assembly ကိရိယာများကို အသုံးပြု၍ အစိတ်အပိုင်းများကို တနေရာကိုတည်း စုစည္းတင်ဆက်နိုင်သည်  
-   TODO အင်္ဂါရပ်: ဝါယာများ (wires) နှင့် ပုံကြမ်းများ (sketches) မှ လမ်းကြောင်း (trajectory) ဖန်တီးခြင်း

## တပ်ဆင်ခြင်း

### အလိုအလျောက် တပ်ဆင်ခြင်း 

ဤ လုပ်ငန်းခွင်ကို [Addon Manager](Std_AddonMgr.md) မှ တပ်ဆင်နိုင်သည်။

 
### GitHub မှ

Ubuntu & Mint ပေါ်တွင် git သုံး၍:

-   ကီးများ **Ctrl**+**Alt**+**t** ဖြင့် command prompt (terminal) ကို ဖွင့်ပါ  
-   git ကို တပ်ဆင်ပါ: {{Incode|sudo apt-get install git}}  
-   repository ကို clone လုပ်ပါ: {{Incode|<nowiki>git clone https://github.com/JMG1/ExplodedAssembly ~/.FreeCAD/Mod/ExplodedAssembly</nowiki>}}

ဒါဆို အကုန်ပါပြီ၊ နောက်တစ်ကြိမ် ဖရီးကက် (FreeCAD) ကို ဖွင့်သောအခါ လုပ်ငန်းခွင်ကို အသုံးပြုနိုင်ပါလိမ့်မည်။

လက်ကိုင်တပ်ဆင်ရန် အတွက် ဤ repository ကို ZIP အဖြစ် ဒေါင်းလိုဒ်ပြီး အောက်ပါနေရာတွင် ဖွင့်၍ ထည့်ပါ။

-   Ubuntu, Mint နှင့် ဆင်တူ OS များအတွက် ဖိုင်များကို ထည့်ရန်: **/home/username/.local/share/FreeCAD/Mod** (<small>(v0.20)</small>) သို့မဟုတ် **/home/username/.FreeCAD/Mod** ({{VersionMinus|0.19}})  
-   Windows အတွက် ဖိုင်များကို ထည့်ရန်: **C:\Users\your_user_name\AppData\Roaming\FreeCAD\Mod**
